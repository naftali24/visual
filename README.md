# אטלס הסוס

## פתיחה במחשב Windows

חלץ את כל קובצי ה־ZIP לתיקייה אחת. פתח את index.html מתוך התיקייה המחולצת ב־Chrome או ב־Edge. שמור את מבנה התיקיות כפי שהוא. אין צורך בהתקנה או בשרת מקומי.

## העלאה ל־GitHub Pages

העלה את תוכן תיקיית Horse_Anatomy_Atlas לענף שממנו האתר מתפרסם. השאר את index.html בשורש התיקייה שתפורסם, ואת images ו־data לצדו. הנתיבים בקוד יחסיים לתיקיית העמוד.

## מבנה הקבצים

| קובץ | תוכן |
| --- | --- |
| index.html | מבנה העמוד ונתיבים לקבצים |
| styles.css | עיצוב, צבעים ושקיפות |
| app.js | ציור הכפתורים והקווים, בחירת שפה והקראה |
| images/horse-anatomy.webp | תמונה אחת של הסוס עם האיברים משולבים בתוכה |
| data/horse/atlasButtons.js | שמות הכפתורים בעברית ובאנגלית, נקודות החיבור של הקווים |
| data/horse/atlasExplanations.js | הסבר בעברית ובאנגלית לכל איבר, לפי אותו מזהה |

לדוגמה, הכפתור Heart משתמש במזהה heart. ההסבר שלו נמצא תחת אותו מזהה בקובץ atlasExplanations.js. כדי להכין עמוד לאיור נוסף, אפשר להעתיק את index.html לשם חדש באותה תיקייה ולשנות בו את נתיבי התמונה ושני קובצי הנתונים. האיור החדש צריך נתוני מיקום משלו. כאשר ממדי האיור שונים, יש להתאים גם את מידות רכיב התמונה ואת הפריסה בקוד.

קובצי הנתונים נטענים כסקריפטים רגילים כדי שהעמוד ייפתח ישירות מהדיסק. התמונות והתוכן המובנה באנגלית ובעברית זמינים מקומית. תרגום אוטומטי לשפות נוספות דורש חיבור ל־Google Translate. השמע תלוי במנוע ההקראה של הדפדפן.

האיור הוא היטל לימודי במבט צד שמציג איברים שנמצאים בעומקים שונים. מיקום הלב נבדק מול [תצלומי האנטומיה של הלב בסוס](https://doi.org/10.1111/apha.13925). מיקום איברי הבטן מסתמך על [Anatomy of the Horse](https://equinetherapies.net.au/wp-content/uploads/2020/12/Anatomy-of-the-Horse-6th-Edition.pdf).
