# ספר ויזואלי של נפתלי

[פתיחת הספר](https://naftali24.github.io/visual/)

## מבנה המאגר

| נתיב | תפקיד |
| --- | --- |
| index.html | דף בחירת נושא ושפה |
| topics/ | עמוד HTML לכל נושא, בתיקייה עם שם הנושא באנגלית |
| images/ | כל האיורים בקובצי WebP, ובתיקיית images/icons גם סמלי האפליקציה |
| data/ | קובצי הכפתורים וההסברים, בתת־תיקייה לכל נושא |
| css/ | קובצי עיצוב לדף הראשי ולעמודי הנושאים |
| js/ | קוד לדף הראשי ולעמודי הנושאים |
| manifest.webmanifest | הגדרות ההתקנה במסך הבית |

## הוספת נושא

שמור את תמונת הנושא ב־images, את נתוני הכפתורים וההסברים ב־data תחת שם הנושא, ואת העמוד בתיקייה topics/<topic>/index.html. אם לנושא יש קוד או עיצוב משלו, שמור אותם ב־js וב־css. השתמש בנתיבים יחסיים מתוך העמוד כדי שייטען גם תחת כתובת GitHub Pages של המאגר.

הוסף קישור לעמוד בתוך מקטע visual-topics באינדקס. שמור על כתובת העמוד לאחר הפרסום כדי שקיצורי דרך קיימים ימשיכו לעבוד.
